# Producto

## Usuario

Una sola persona: psicóloga, con un instrumento psicométrico en validación,
construyendo autoridad pública en salud mental desde Chile. Opera todo el
sistema sola y responde profesionalmente por lo que publica.

## Propósito

Cerrar un ciclo de cuatro tiempos: capturar materia prima, destilar contexto y
voz validados, producir piezas con control de calidad, medir y volver.

El activo que se construye **no es el software, es el Cerebro**: un corpus de
hechos verificados y voz textual propia que crece con el uso y no se copia. El
software es andamio. Si hay que elegir entre construir más andamio y llenar el
Cerebro, se elige lo segundo.

## Anti-referencias

Lo que este sistema no debe producir nunca:

- **Contenido que suene a IA.** Texto con gradiente conceptual, superlativos sin
  respaldo, listas de tres con ritmo idéntico, cierres motivacionales vacíos.
- **Afirmaciones de eficacia clínica sobre un instrumento en validación.** Es el
  error más caro posible y el sistema existe en buena parte para impedirlo.
- **Citas que la persona no dijo.** Ni una.
- **Urgencia artificial.** Escasez inventada, plazos falsos, presión de compra.
- **Sobreexposición por inercia.** Si una pieza cruza un límite declarado en la
  fase 0, se avisa antes de publicar.
- **Decks que parezcan Google Slides.** Plantilla de título centrado, ritmo de
  agenda, grillas de tarjetas idénticas con ícono, métrica gigante con etiqueta
  chica.

## Principios

1. El Cerebro es la única fuente citable. Lo demás es contexto.
2. La máquina propone, la persona valida.
3. Los guardrails protegen lo que sale; la fase 0 protege a quien lo produce.
4. Ningún juicio de modelo se presenta como medición.
5. El sistema debe poder decir "todavía no sé", y decirlo seguido.
